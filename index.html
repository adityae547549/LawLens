Everything you need to know about LawLens.

LawLens uses Retrieval-Augmented Generation (RAG), meaning every answer is grounded in actual legal documents. The AI never answers from memory — every fact is cited from the retrieved context. Confidence scores show you how reliable each answer is.
No. LawLens is a research tool, not a lawyer. It explains legal documents in simple language and provides citations. It never provides personalized legal advice or attorney-client recommendations.
LawLens supports PDF, DOCX (Word), TXT, JSON, and Markdown files. You can upload constitutional texts, case law databases, legal textbooks, statutes, and more.
RAG (Retrieval-Augmented Generation) works in 4 steps: 1) Your question is converted to a search query. 2) The system finds the most relevant document chunks using hybrid search. 3) A cross-encoder reranker selects the best matches. 4) The AI generates an answer using ONLY the retrieved context, citing every source.
